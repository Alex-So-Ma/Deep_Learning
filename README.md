# Deep_Learning
Contains Jupyter Notebooks focusing on deep learning tasks and projects. It includes:

IAF_Tareas 1-5: Assignments from the Artificial Intelligence in Physics course at the National Autonomous University of Mexico (UNAM). Assignments regarding the basics of neural networks, the use of pandas, and neural network applications.

IAF_Proyecto_Final (M1, M2, M3): The final project for the Artificial Intelligence in Physics course, is divided into three parts. The first and the third parts are convolutional neural networks used to classify MRIs of brain tumors, in the third one data augmentation is used. The second one is an attempt to use UNet to solve the problem, but I did not have access to a good computer at the time.

IRN_Proyecto_Final: Another final project for a course named Introduction to Neural Networks, uses a dense layer Neural Network to classify astronomical objects.

IRN_Tarea_Vinos: An assignment for the Introduction to Neural Networks course at UNAM, uses a dense layer Neural Network to classify wines.

NN_BM_v3_sin_ejecutar.ipynb: An unexecuted version of a project. It was done at the Centro de Ciencias de la Complejidad (C3), an institute of UNAM. It uses bibliographic information from the online database Web of Science. Then that information was used for author name disambiguation, the disambiguation process was done with convolutional neural networks.

TensorFlow/Keras for building and training neural networks, including convolutional and dense networks. NumPy is used for numerical operations, while Pandas handles data processing. Matplotlib and Seaborn are employed for data visualization, and Scikit-learn is used for tasks like model evaluation and splitting data. These libraries enable model development, data manipulation, and analysis throughout the deep learning projects.
